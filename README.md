# 채용 안내 포털

부서 업무 포털 샘플입니다. 바이브 코딩 2강 실습으로 만들었습니다.

## 주소

https://saykima02.github.io/dept-portal

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 포털 첫 화면 (상단 메뉴 · 채용 절차 · FAQ · 자료실) |
| `files/` | 자료실에서 내려받는 PDF · Word 파일 |

## 내용을 고치려면

1. 바탕화면 `부서포털` 폴더에서 `index.html`을 고칩니다.
2. 저장소 화면에서 **Add file › Upload files**를 누릅니다.
3. 고친 파일을 끌어다 놓고 **Commit changes**를 누릅니다.
4. 1~2분 뒤 같은 주소에 반영됩니다. 주소는 바뀌지 않습니다.
